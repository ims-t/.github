# IMS-T@gbssg.ch 👨‍💻

Welcome to the GitHub organisation of **IMS-T – Informatikmittelschule Technik** at the **Gewerbliche Berufsschule St. Gallen (GBS)**.

This organisation contains projects developed by IMS-T students during their education.

## 🚀 Projects

Our repositories include student projects covering areas such as:

* Software development
* Embedded systems and microcontrollers
* Web development
* Networking and communication
* Automation and IoT
* Individual and team projects

The project repositories use the `project.*` naming convention.

## 🛠 Technologies

Depending on the project, we work with technologies such as:

`C#` · `C++` · `HTML/CSS/JavaScript` · `Git` · `GitHub` · `Arduino / ESP32`

## 🎓 About IMS-T

The **IMS-T** combines vocational IT education with the Swiss Berufsmaturität and practical software and engineering projects.
